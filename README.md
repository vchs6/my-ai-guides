# my-ai-guides

Layered AI development guidance for multi-project teams — prompt-as-code, agent harness, battle protocols, templates and ops.

This repository contains a multi-layer documentation scaffold intended for organizations that run multiple AI subprojects in parallel. Files are organized by responsibility layer so each team can maintain its own docs, templates and tests while sharing governance and platform services.

Structure

- docs/en: English docs (layered)
- docs/zh: 中文文档（分层）

Browse the English docs in docs/en/ or Chinese docs in docs/zh/.

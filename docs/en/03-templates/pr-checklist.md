# PR Checklist (must be completed for every PR altering prompts, tests or battle cases)

- [ ] Template metadata present (id, version, author, purpose)
- [ ] Examples and expected outputs included
- [ ] Output JSON Schema provided and validated
- [ ] Unit tests added/updated and passing
- [ ] Battle subset added/updated (if risk >= medium)
- [ ] Privacy/PII check completed
- [ ] Security scan (injection patterns) passed
- [ ] Reviewers: template owner, platform owner, security (if medium/high)

Merging is blocked until checklist is complete.

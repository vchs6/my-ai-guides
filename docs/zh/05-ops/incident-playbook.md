# 事件响应手册 — AI 系统

范围

本手册涵盖 AI agent 产生有害输出、泄露敏感数据或导致未预期外部副作用的事故。

立即步骤（前 15 分钟）

1. 停止新请求：切换功能开关或将流量重定向到安全回退。
2. 捕获日志与会话快照（request id、prompt id、模型名、原始输出）。
3. 通过 PagerDuty/Slack 通知值班 SRE + 安全团队，并标记 `ai-incident`。

分类与初步处置（15-60 分钟）

1. 分类事故：幻觉 / PII 泄露 / 外部动作 / 其他。
2. 若为 PII 泄露：联系隐私官评估并按策略通知相关方。
3. 若是发布变更导致，开始回滚流程。

恢复与事后分析

- 在补丁与回归测试通过后恢复服务。
- 在 72 小时内撰写事后分析报告，包含根因、修复与后续行动（例如增加测试、监控）。
